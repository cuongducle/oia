Install help

Two minutes, no account.

Oia ships as a plain installer for macOS and Windows. The builds are unsigned (no signing budget yet), so the first open needs one extra click, here is exactly what you will see.

Download Oia All releases

v0.6.0 · ~410 MB · macOS 13+ (Apple Silicon) / Windows 10+

Which build do I need?

macOS · Apple Silicon

Oia-arm64.dmg, for M1, M2, M3 and M4 Macs (macOS 13 or newer). This is the build the Download button picks on a Mac. Open the .dmg and drag Oia to Applications.

Windows · 64-bit

Oia-win-x64.exe, Windows 10/11, installs per-user into %LOCALAPPDATA%\Programs\Oia (no admin). Your projects live in %APPDATA%\Oia and survive uninstall and upgrade.

macOS · Intel

There is no Intel build yet. You can still run Oia by building from source, or watch the releases page; an x64 build is a packaging task, not a rewrite.

iPhone / iPad / Android

Oia is a desktop app, there is no mobile build. The website works on anything; the studio needs macOS or Windows.

First open: the security prompts

Unsigned does not mean broken. It means macOS and Windows show one warning because they have not seen this developer before. Both OSes offer a built-in way through.

macOS: “can’t be opened” / unidentified developer

In Applications, right-click Oia → Open → Open. The right-click route is the built-in Gatekeeper bypass for unsigned apps. If the dialog still bothers you: System Settings → Privacy & Security → scroll to the bottom → Open Anyway.

macOS: “is damaged and can’t be opened”

This is the quarantine flag some browsers add, not real damage. Open Terminal and run:

xattr -d com.apple.quarantine /Applications/Oia.app

Then open Oia normally.

Windows: “Windows protected your PC”

SmartScreen shows this for unknown publishers. Click More info → Run anyway. The installer needs no admin rights.

Antivirus scanning the .exe

Unsigned installers occasionally get flagged. The release publishes checksums-*.txt next to each file, compare with shasum -a 256 <file> if you want to verify the download.

First run

1 · Explore with zero setup

Oia opens with a bundled sample project and the mock provider, real text and object editing, no login, nothing generated.

2 · Sign in to generate

Open Runtime in the app, sign in with ChatGPT, and generations run on your plan quota through the bundled Codex CLI. No API key needed. OpenAI/fal keys work too.

3 · No auto-update (yet)

Until the builds are signed there is no update channel, pick up new versions from the releases page. Your projects survive upgrades.
