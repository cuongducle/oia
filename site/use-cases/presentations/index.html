The outline gate

01 — ASK

One prompt, N pages

"An 8-page product-launch deck for a skincare serum" — set pages 3–9 in the composer.

02 — REVIEW

Outline first, zero images

The deck stops at an outline card: rewrite any page title or summary before painting. Outline edits are free.

03 — PAINT

One style across pages

Every page generates from the same plan and brand kit — consistent palette, layout and type.

04 — EXPORT

PDF & PPTX

PDF preserves mixed page sizes; PPTX puts each page on a slide. Edit any page on the canvas before you ship.

Why it's different

No surprise 30-slide bills

The outline is the contract — page count is locked before a single image is spent.

Real pages, real edits

Each page is a canvas — move the headline, restyle a chart card, duplicate a page for the next chapter.

Brand kit on every page

Palette and guidance ride the whole deck, not just page one.

Your quota, your rules

≈ N images shown up front, a daily counter in the sidebar. No credits, no subscription.

Can I review the deck before images are generated?

Yes — multi-page requests stop at an outline card first: page titles and summaries you can rewrite before anything is painted. Outline edits cost zero images.

Can I export to PowerPoint?

Yes — PPTX places each rendered page on a slide, and PDF preserves mixed page sizes. Canvas text layers are not converted into native PowerPoint text boxes.
